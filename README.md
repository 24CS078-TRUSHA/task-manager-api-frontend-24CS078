# Task Manager Frontend

This is the React frontend for the Practical 6 Full Stack Task Management Application.

The frontend communicates with the Node.js + Express backend through REST API calls.

---

## Technologies Used

- React
- JavaScript
- Vite
- HTML
- CSS
- Fetch API
